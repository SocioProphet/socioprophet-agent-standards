# Workspace Context Fabric standards

This directory contains the agent-facing compatibility profile for Workspace Context Fabric.

The profile binds workspace, platform, execution, recall, authority, and estate-registration surfaces without moving their contract ownership into this repository.

## Current standards

- `001-workspace-context-fabric-profile.md` — v0.1 profile and conformance boundary for the first Workspace Context Fabric tranche.

## Boundary

This directory owns profile and conformance expectations only.

Service contracts remain in their owning repositories:

- `prophet-workspace`
- `prophet-platform`
- `agentplane`
- `memory-mesh`
- `agent-registry`
- `sociosphere`
